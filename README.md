## 🕹️ **Tentang Game Ini**

**Guess Who: Multiverse Edition** adalah game browser yang terinspirasi dari game klasik *Guess Who*,
tetapi dengan sentuhan dunia modern dan karakter favorit dari berbagai franchise terkenal.
---

## ⚡ **Fitur Utama**

✨ **5 Dunia Berbeda** — Dari Teyvat hingga Overworld.  
🎨 **Tampilan Dinamis** — Setiap tema punya gaya visual unik.  
🔍 **Filter Pintar** — Gunakan kategori untuk mempersempit pilihan (Vision, Type, World, dll).  
🎲 **RNG System** — Karakter diacak setiap ronde.  
💾 **Auto Reset & Responsif** — Grid tetap konsisten di semua perangkat.  
🌈 **Tanpa Instalasi** — Main langsung di browser, tanpa ribet!

## 🧠 **Cara Bermain**

### 🎮 1. Pilih Tema
Pilih dunia yang ingin kamu mainkan: **Genshin**, **Honkai**, **Pokémon**, **Minecraft**, atau **PvZ**.

### 🧩 2. Gunakan Filter
Gunakan dropdown untuk menyaring karakter berdasarkan kategori:

- **Genshin** → Vision, Region, Weapon  
- **Honkai** → Path, Element, World  
- **Pokémon** → Type, Generation, Evolution  
- **Minecraft** → Type, Biome  
- **PvZ** → Type (Plant/Zombie), World, Sun Cost  

### 👆 3. Eliminasi Karakter
Klik karakter yang **tidak sesuai petunjuk** untuk menghapus mereka dari papan.

### 🎲 4. Acak Ulang
Gunakan tombol **RNG** untuk memulai ronde baru dan mengatur ulang semua filter.
